# 分貝計 · Sound Meter

單一檔案的網頁分貝計（`index.html`），不需安裝任何套件。

- 即時顯示音量（Fast 125 ms 時間加權）、最高值、平均值與近 30 秒曲線
- 音量 **大於門檻（預設 70 dB）** 時：播放警告聲 → 語音「警告警告，音量過大，請立即降低聲音。」
- 每輪結束後靜音量測約 0.75 秒，**仍高於門檻就繼續循環**，低於門檻才停止
- 門檻與校正偏移會儲存在瀏覽器中

## 使用方式

麥克風需要在 HTTPS 或 `localhost` 下才能使用：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

或在 GitHub 設定中開啟 Pages，直接用手機開啟網址。

## 關於準確度

瀏覽器只能取得相對音量（dBFS），顯示值 = dBFS + 校正偏移。
若有標準分貝計或可信的手機 App，可調整「校正偏移」使讀數一致。
